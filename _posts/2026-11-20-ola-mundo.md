Este é o primeiro post. Para escrever um novo, crie um arquivo em `_posts/` com o nome no formato `AAAA-MM-DD-titulo.md` e um cabeçalho assim:

```yaml
---
layout: post
title: Título do post
subtitle: Uma linha opcional de resumo
---
```

Depois é só escrever em **Markdown**.

## Um pouco de código

```python
def saudacao(nome: str) -> str:
    # Retorna uma saudação simples
    return f"Olá, {nome}!"
```
